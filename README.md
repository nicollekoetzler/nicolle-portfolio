# Nicolle Koetzler · Portfolio

Next.js (App Router) site built from the Figma file "Nicolle Website" (frame NK Website Portfolio).

```bash
npm install
npm run assets   # downloads the images from Figma into public/assets
npm run dev      # http://localhost:3000
```

Edit projects and roles in `app/data.ts`; styles live in `app/globals.css`.
